# RedForge

Curated offensive-security skills for LLM-assisted red teaming: structured `SKILL.md` files, CLI helpers, and an optional local UI.

**Documentation, skills, and tools:** [`redforge/README.md`](redforge/README.md)

**Quick start:**

```bash
cd redforge
python3 tools/redforge.py list
```

For kill-chain combinations and the combined master system prompt, see [`redforge/MASTER_INDEX.md`](redforge/MASTER_INDEX.md).
